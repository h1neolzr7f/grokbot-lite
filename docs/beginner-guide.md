# 新手教程：从买服务器到连上 Grok Bot（无截图版）

全程大约 **15–20 分钟**。你需要：一个 Grok Bot 账号、一台电脑或手机上的浏览器、一个能付款的云厂商账号。

## 第 1 步：买一台服务器

推荐配置（够用且便宜）：

| 项目 | 选择 |
| --- | --- |
| 产品 | 阿里云「轻量应用服务器」/ 腾讯云「轻量应用服务器」/ 其他 KVM VPS |
| CPU / 内存 | **2 核 2 GB**（实测）；1 GB 也能跑但要开 swap |
| 系统镜像 | **Ubuntu 24.04**（选纯净系统镜像，不要选“应用镜像”） |
| 硬盘 | 默认 40 GB 足够（本项目需要约 1.2 GB） |
| 地域 | 离你近的即可 |

价格经常有新用户活动，以厂商页面为准。**不要**选 CentOS、Alibaba Cloud Linux、Windows，也不要选 32 位 ARM。

## 第 2 步：设置登录密码 / 密钥

在云厂商控制台找到这台服务器 →「重置密码」或「绑定密钥」。记下：**公网 IP**、用户名（通常是 `root`，腾讯云 Ubuntu 镜像常是 `ubuntu`）、密码。

> 安全组/防火墙**不需要**额外放行任何端口，保持默认（只开 22 端口用于 SSH）即可。

## 第 3 步：连上服务器

- **最简单**：在云厂商控制台点「远程连接」/「登录」（网页终端，阿里云叫 Workbench，腾讯云叫 OrcaTerm）。
- **Windows**：打开「终端」或 PowerShell，输入 `ssh root@你的公网IP`，第一次问 `yes/no` 输入 `yes`，再输密码（输入时不显示，正常）。
- **macOS / Linux**：打开终端，同上。

看到类似 `root@xxx:~#` 就是连上了。

## 第 4 步：运行一键安装

复制粘贴这一行，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/YOUR-GITHUB/grokbot-lite/main/install.sh | sudo bash
```

> 如果你是 `ubuntu` 用户，`sudo` 可能会问一次密码，就是你在第 2 步设置的密码。

接下来脚本会：
1. 检查环境，绿色 ✔ 表示没问题；
2. 问你要不要创建 swap —— **直接回车**（默认“是”）；
3. 自动下载安装（约 350 MB，几分钟，取决于网速）。

## 第 5 步：登录 Grok Bot（最关键的一步）

脚本会显示一个黄色大框，里面有一个以 `https://` 开头的链接和一个二维码：

1. 在**你自己的**浏览器里打开链接（或用手机扫码）；
2. 确认浏览器里登录的是**你要用的那个 Grok Bot 账号**（很多人在这里登错号）；
3. 点击同意/授权；
4. 回到终端，倒计时消失、出现「✔ 登录成功」。

链接**一次性**，约 24 分钟内有效；**不要发给任何人**，谁打开谁就能控制这台服务器。超时了也没关系，重新运行第 4 步的命令即可（前面的步骤会自动跳过）。

## 第 6 步：确认成功

最后会看到绿色框：

```text
🎉 安装完成！这台机器现在可以被 Grok Bot 远程使用了
后台 122 MB + 监督进程 70 MB = 约 192 MB 内存
```

然后在 Grok Bot 里查看你的机器列表，应该能看到这台服务器。让 Grok Bot 在上面跑一条 `uname -a` 试试——
它会先请求你批准（这是 `ask` 策略在保护你）。

## 第 7 步：以后要做的事

| 什么时候 | 做什么 |
| --- | --- |
| 偶尔看看状态 | `sudo grokbot-lite doctor` |
| 系统升级了 grok-bot（`apt upgrade` 后） | `sudo grokbot-lite fix --restart` |
| 登录错账号 / 想换账号 | `curl -fsSL …/install.sh \| sudo bash -s -- --switch-account` |
| 不用了 | `curl -fsSL …/install.sh \| sudo bash -s -- --uninstall` |

遇到问题先看 [新手 FAQ](faq.md)，再看日志 `sudo tail -n 50 /var/log/grokbot-lite-install.log`。
